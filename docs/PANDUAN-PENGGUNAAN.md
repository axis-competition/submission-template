# Panduan Menggunakan Template Repository AXIS 2026

Dokumen ini ditujukan bagi peserta yang ingin menyusun dokumentasi kode sumber secara rapi.

## Cara menggunakan

1. Buka repository `submission-template` milik organisasi `axis-competition` setelah tersedia.
2. Jika tersedia tombol **Use this template**, buat repository pada akun atau organisasi milik tim.
3. Ganti semua penanda `[ ... ]` di `README.md` dengan informasi proyek yang sebenarnya.
4. Unggah kode sumber asli dan dokumen teknis yang diperlukan, tanpa rahasia atau data sensitif.
5. Pastikan README mencantumkan persyaratan sistem, cara instalasi, struktur basis data, dan cara menjalankan aplikasi.
6. Periksa akses repository untuk dewan juri. Jika repository bersifat privat, koordinasikan akses secara terpisah dengan panitia.
7. Kirim **tautan repository karya** melalui Google Forms pengumpulan karya resmi, bukan sekadar tautan profil GitHub ketua tim.

## Ketentuan kompetisi berdasarkan guidebook

- Peserta: mahasiswa S1; tim berisi 2 sampai 4 orang.
- Setiap tim mendaftarkan satu karya pada satu kategori studi kasus.
- Backend wajib menggunakan PHP dan basis data MySQL.
- Aplikasi harus online untuk penjurian, responsif, interaktif, memiliki CRUD, autentikasi, dan sedikitnya dua peran pengguna.
- Dokumen ringkasan karya: **PDF 5 sampai 7 halaman**.
- Video demonstrasi: **maksimal 3 menit**.
- Batas pengumpulan karya: **9 Desember 2026 pukul 23.59 WIB**.
- Tautan pengumpulan resmi: https://forms.gle/z6LmuzqaYRqVUZaNA

## Keamanan dan kerahasiaan

Jangan menyimpan password akun demo, token, kunci API, data pribadi anggota, KTM, bukti transfer, atau isi basis data sensitif dalam repository publik. Berikan akun demo hanya melalui kanal yang ditentukan panitia.

## Perbedaan dua tautan GitHub

- **Profil GitHub ketua tim:** misalnya `https://github.com/username`, untuk identifikasi akun pengembang.
- **Repository karya:** misalnya `https://github.com/username/nama-proyek`, untuk pemeriksaan kode sumber aplikasi.

Tautan repository karya wajib disampaikan pada tahap pengumpulan, bukan hanya pendaftaran.
